# Bus Route Planner Using Data Structures in C

## Project Description

The Bus Route Planner is a simple C programming project developed using data structures. It helps users manage bus stops, display bus routes, and find routes between two stops.

## Features

* Add bus stops
* Add bus routes
* Display all bus routes
* Find a route between two bus stops
* Simple menu-driven interface

## Data Structures Used

* Structures
* Arrays

## Programming Language

C

## How to Run

1. Download or clone this repository.
2. Open the C file in a C compiler.
3. Compile and run the program.
4. Follow the menu options displayed on the screen.

## Objective

The main objective of this project is to understand the practical application of data structures in bus route management.

## Conclusion

This project demonstrates how arrays and structures can be used to store bus stop details and manage routes efficiently.
